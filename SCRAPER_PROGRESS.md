# State Scraper Progress

Progress tracker for finishing out the state scrapers built on the JKent framework.

Checklist items per scraper:
- **Small test** — small/offline test fixture passing
- **Backscrape** — historical backscrape implemented & run
- **Ongoing job** — ongoing/incremental scrape job configured
- **Affidavit** — affidavit written
- **CL models** — CourtListener models mapped
- **CL merger** — CourtListener merger implemented
- **Writeup** — documentation / writeup complete

Legend: `[ ]` todo · `[x]` done
